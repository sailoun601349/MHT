## 4. 验收测试清单（P8）

```text
[用户端]
1. 输入无效手机号 → 提示且不进入下单
2. 仅手机号 → 进入下单页
3. 手机号+错误查询码 → 提示订单不存在
4. 下单成功 → 查询码格式 = 手机号 + 三位全局序号
5. 连续两人下单 → 002、003（全局递增）
6. 同人再下单 → 序号继续全局递增
7. 未发货订单查询 → 显示"待发货"，无快递信息
8. 多地址下单（3 个地址）→ 一个查询码 + 3 条订单，总价 = 各小计之和
9. 用户查询一码 → 可左右/上下切换查看 3 个地址
[管理端]
10. 错误登录密码 → 拒绝，连续 5 次锁定 10 分钟
11. 正确登录 → 订单列表可见
12. 发货：上传照片+填单号 → 状态变已发货
13. 用户端可见快递公司/单号/照片
14. 上传 .exe / >10MB 文件 → 被拦截
15. 伪造 created→completed、completed→cancelled 等非法流转 → 均被后端拒绝
16. 取消订单不填原因 → 拒绝；填原因后成功且详情可见
[其他]
17. 手机浏览器与电脑浏览器均正常（响应式）
18. 重启进程后数据不丢失
19. 旧数据库迁移后 sub_no=1，查询/管理均正常
```
