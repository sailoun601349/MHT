# 猕猴桃订单系统 · UI 设计规范（Design Spec）

> 版本：v1.0（2026-09-03）
> 适用范围：顾客端（手机优先）+ 管理员端（手机 + 电脑）
> 技术基座：Bootstrap 5.3 + Jinja2，无需前端构建工具

---

## 1. 设计理念

猕猴桃是「产地直发」的生鲜产品，界面要传达 **自然、新鲜、可信赖、简单** 的气质；管理员端则要 **信息密度高、操作高效、责任清晰**。

三条设计原则：

| # | 原则 | 落地表现 |
|---|---|---|
| P1 | 手机优先 | 顾客全流程单手可完成；触控区 ≥ 48px；大按钮、大输入框 |
| P2 | 品牌即色彩 | 猕猴桃绿为主色，传递自然新鲜；琥珀暖橙做关键动作与金额强调 |
| P3 | 语义清晰 | 状态/角色/金额统一色板，一眼可辨，不靠文字猜 |

### 2.2 字体

```css
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
```

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 18px | 500 | 页头 H5 |
| 卡片标题 | 15px | 500 | 卡片/区块标题 |
| 正文 | 14px | 400 | 表格、正文 |
| 辅助 | 13px | 400 | 说明、标签、次文本 |
| 弱提示 | 12px | 400 | 时间、占位、脚注 |

> 中文字重仅用 400 / 500 两档，避免发虚。

### 2.3 间距（8pt 体系）

`4 / 8 / 12 / 16 / 24 / 32 / 48`，组件内部用 px（8/12/16），页面纵向节奏用 rem（1 / 1.5 / 2）。

### 2.4 圆角与阴影

| 元素 | 圆角 |
|---|---|
| 输入框 / 小按钮 | 8px |
| 卡片 / 大按钮 | 12px |
| 弹窗 / 大容器 | 16px |

阴影仅用于「浮起感」：卡片 `0 1px 3px rgba(0,0,0,.06)`，弹窗 `0 10px 24px rgba(0,0,0,.12)`。全局不使用渐变。

## 3. 组件规范

### 3.1 按钮

| 变体 | 背景 | 文字 | 用途 |
|---|---|---|---|
| 主按钮 | `#3D8B5F` | 白 | 提交订单、登录、创建 |
| 强调按钮 | `#E08A3C` | 白 | 立即购买、关键转化 |
| 次按钮 | 白 + 边框 | `#1F2937` | 取消、次要动作 |
| 危险 | 白 + 红边 | `#DC2626` | 删除、停用 |

- 最小触控高度 48px（`min-height`）。
- hover：主色加深为 `#2E6B47`，轻微上浮 1px。
- disabled：透明度 0.6 + `not-allowed`。

### 3.2 表单输入

- 输入框高 ≥ 48px（手机），圆角 8px，边框 `#E5E7EB`。
- 聚焦：边框变 `#3D8B5F` + 2px 外发光（`rgba(61,139,95,.15)`）。
- 必填星号用红色 `#DC2626`，占位符用 `#9CA3AF`。

### 3.3 状态徽章

药丸形（`border-radius: 999px`），字号 12px，padding `3px 10px`，见 2.1 对照表。

### 3.4 卡片

白底、1px 边框 `#E5E7EB`、圆角 12px、内边距 16px；标题 15px/500，正文 13px。

## 4. 页面设计要点（逐页）

### 4.1 顾客首页（`index.html`）

- 顶部品牌区：猕猴桃绿文字「猕猴桃订购」+ 副标「太白山 · 产地直发」。
- 主输入：手机号大输入框（`inputmode=numeric`）+「进入下单」主按钮。
- 辅助入口：「查询订单」（手机号 + 查询码）。
- 目标：3 秒看懂、1 步进入。

### 4.2 下单页（`order/new.html`）

- 顶部固显「下单手机号」。
- 收货地址卡片：可增删，支持多地址；删除按钮仅多地址时可见。
- 规格用「选中态」高亮（浅绿底 + 绿描边），数量用步进/数字输入。
- 每个地址「小计」右对齐；底部「总费用」大字号（24px/500）绿字 + 浅绿底。
- 提交按钮全宽主色，提交后禁用并显示「提交中…」。

### 4.3 成功 / 查询页

- 大号查询码展示（letter-spacing 加宽，便于抄录），配「复制查询码」次按钮。
- 多地址订单用卡片分列，状态徽章标注。

### 4.4 管理员登录（`admin/login.html`）

- 居中窄卡片（桌面 ≤ 480px），主色「管理员登录」标题。
- 输入框 label 统一「登录密码」（术语统一，见 PRD R2）。
- 主按钮全宽登录，底部灰字「返回首页」。

### 4.5 订单管理（`admin/orders.html`）

- 顶部：标题 + 总笔数。
- **统计卡片**（超管/个人都可用）：今日订单、待发货、销售额、累计订单。
- 状态筛选：药丸 tab（全部 / 待发货 / 已发货 / 已完成 / 已取消）。
- 搜索：关键词 +（超管）责任人筛选。
- 桌面表格 + 手机卡片双视图；责任人列显示手机号，超管加「· 超管」标记。
- 分页居中。

### 4.6 订单详情（`admin/order_detail.html`）

- 顶部状态徽章 + 查询码 + 子单编号。
- 责任人单独一行高亮（数据隔离可视化）。
- 发货操作：上传面单照片 + 快递公司/单号，用主按钮「确认发货」。

### 4.7 管理员管理（`admin/admins.html`，仅超管）

- 卡片栅格：手机号 + 角色徽章 + 状态徽章。
- 每卡展示「专属短码（完整链接）」+ 创建时间 + 创建者。
- 操作：重置密码 / 停用·启用 / 删除（删除为危险色，二次确认）。

### 4.8 我的专属链接（普通管理员）

- 卡片突出展示完整链接 `http://49.232.88.86:18805/<短码>` +「复制」按钮。
- 短码自定义输入 + 保存；冲突提示。
- 超管则显示「您使用根路径接单」。

### 4.9 修改登录密码

- 三段式：当前密码 + 新密码 + 确认新密码。
- 新密码强度提示（≥6 位），主按钮提交。

## 5. 落地映射（Bootstrap 5 覆盖方案）

无需引入新框架，在 `app/static/css/custom.css` 顶部覆盖 Bootstrap CSS 变量即可最小侵入：

```css
:root {
  --bs-primary: #3D8B5F;
  --bs-primary-rgb: 61,139,95;
  --bs-success: #16A34A;
  --bs-warning: #D97706;
  --bs-danger: #DC2626;
  --bs-info: #2563EB;
  --bs-body-font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
  --bs-body-bg: #F6F8F6;
  --bs-border-radius: 0.5rem;      /* 8px */
  --bs-border-radius-lg: 0.75rem;  /* 12px */
  --bs-border-radius-xl: 1rem;     /* 16px */
}
.btn { border-radius: 0.75rem; }
.card { border-radius: 0.75rem; box-shadow: 0 1px 3px rgba(0,0,0,.06); }
.form-control-lg, .form-select-lg, .btn-lg { min-height: 48px; }
.badge { border-radius: 999px; }
```

改造顺序建议：`base.html`（导航 + 底栏）→ `custom.css`（token + 组件）→ 逐页模板套用新类。

## 6. 无障碍与响应式（WCAG AA）

- 正文对比度 ≥ 4.5:1；大字号（≥18px）≥ 3:1。
- 键盘可完整操作；`:focus-visible` 显示清晰焦点环（主色描边）。
- 触控目标 ≥ 44px（本方案取 48px）。
- 断点：手机 `< 768px` 卡片视图；桌面 `≥ 768px` 表格视图；超大 `≥ 1280px` 居中容器。
