# 规格管理 · UI 设计规范（适配 `docs/12` 新需求）

> 版本：v1.1（2026-09-04，同步 `docs/12` 决策⑦⑧）
> 前置：`docs/12-spec-management-spec.md`（规格与价格管理需求）、`docs/11-ui-design-spec.md`（全局 UI 设计系统）
> 关联改动：下单页规格选择器、超管「规格管理」页、普通管理员「规格」页

---

## 1. 需求映射与关键约束

| 需求点 | UI 层体现 |
|---|---|
| 规格数据库化 | 下单页规格动态渲染（不再依赖 config.SPECS），按 `spec_id` 提交 |
| 规格 × 适用管理员 | 超管「适用管理员」勾选面板；管理员「我适用的」只读列表 |
| 内置规格保护 | 「内置」徽章；**名称与价格 ¥50/¥100 完全锁定**，无改价、无删除，仅可维护适用管理员 |
| 创建者不可移除 | 勾选面板中创建者置灰锁定 |
| 允许重名 | 卡片/列表同时展示「名称 + 价格」以区分 |
| 下架 / 删除语义 | 状态徽章「启用/下架」；下架保留适用关系，删除清关系 |
| **规格数量 2~20** | 见 §1.1，下单页选择器按 2~20 设计；创建/分配时做配额与上限提示 |

### 1.1 规格数量边界（用户确认：最少 2、最多 20）

两条独立口径（来自 `docs/12` 决策⑦）：

| 口径 | 规则 | UI 提示 |
|---|---|---|
| **创建配额（不含内置 2 个）** | 超管名下可建自定义规格 ≤ 20；普通管理员 ≤ 10 | 新建规格时显示「还可创建 N 个」，配额用尽禁用新建 |
| **适用上限（含内置）** | 任一管理员「适用」的规格合计 ≤ 20（内置 2 + 他人开放 + 自己创建） | 超管给某管理员分配规格时，若已达 20，提示「该管理员适用规格已达 20 个上限」 |

- **下单页规格选择器承载 2~20**：下限 2 由内置 `5斤装`/`10斤装` 兜底（任何管理员天然 ≥ 2 个可售规格）；上限 20 即适用上限。2 列网格 ≤ 10 行，无溢出。

## 2. 下单页规格选择器（核心）

### 2.1 组件形态

单选卡片组（radio 语义），每卡片固定「名称 + 价格」，选中态 = 2px 绿描边 + 浅绿底 + 右上角对勾。

### 2.2 数量自适应（2 → 20）

| 规格数 | 布局 | 卡片规格 |
|---|---|---|
| 2 个 | 2 列「大卡片」 | 名称 14px/500，价格 18px/500，内边距 14px，圆角 12px |
| 3~6 个 | 2 列标准卡片 | 名称 13px/500，价格 15px/500，内边距 11px，圆角 10px |
| 7~20 个 | 2 列紧凑卡片 | 名称 12px/500，价格 14px/500，内边距 9px，圆角 10px |

> 手机端始终 2 列；桌面（管理员预览）可放宽至 3~4 列。多地址下单时，每个地址独立一套选择器。

### 2.3 关键规则

- 价格展示两位小数（整数可简写，如 `¥50.00`）；价格色统一用猕猴桃深绿 `#2E6B47`。
- 重名规格靠价格区分，卡片名称下紧跟价格，肉眼可辨。
- 提交携带隐藏 `spec_id`（表单字段名 `spec_id_{I}`，与地址下标一致），服务端按 id 校验「适用 + 启用」并计价。
- 内置规格与自定义规格在下单页**平等展示**，不额外打「内置」标（顾客无需感知）。

### 2.4 空态 / 边界态

- 某管理员适用且启用规格为空（理论上不会，内置兜底）：显示「暂无可售规格，请联系管理员」。
- 规格被下架：下单页即时隐藏（重新渲染）。

## 3. 超级管理员「规格管理」页

### 3.1 表格列

| 列 | 内容 |
|---|---|
| 规格名称 | 内置规格带「内置」徽章 |
| 价格 | ¥ 两位小数；**内置显示「锁定」小标（¥50.00 / ¥100.00 不可改）** |
| 创建者 | 管理员手机号 |
| 状态 | 启用 / 下架徽章 |
| 适用 | 「全部 N 人」（内置默认）/「N 人 · 管理」（自定义，点击打开勾选面板） |
| 操作 | 内置：无改价、无删除，仅「适用」管理；自定义：「改价 / 下架·上架 / 删除 / 适用」 |

### 3.2 适用管理员勾选面板

- 列出全部管理员，复选框多选；**创建者勾选置灰锁定，不可取消**。
- 内置规格：可增删任意管理员（但内置规格本身不可删）。
- 自定义规格：可增补他人，但创建者强制保留。
- 底部「取消 / 保存」，保存提交勾选数组；分配时校验适用上限 ≤ 20。

### 3.3 交互护栏

- 删除：二次确认，提示「删除后适用关系一并清除，历史订单不受影响」。
- 内置规格行：名称只读、价格锁定（无改价入口）、无删除，仅可维护适用管理员。
- 改价弹窗（仅自定义规格）：价格输入 `0 < 价格 ≤ 9999`，两位小数，服务端存分；**内置规格不出现改价入口**。

## 4. 普通管理员「规格」页

两个区块：

| 区块 | 内容 | 可操作 |
|---|---|---|
| 我创建的 | 自己创建的规格（名称 + 价格 + 状态） | 新建 / 改价 / 下架·上架 / 删除 |
| 我适用的 | 内置 + 他人开放给自己的（只读） | 无（只读） |

- 「我适用的」每条标注来源：「默认适用」（内置）或「由超管开放」（他人）。
- 管理员只能改自己创建规格的价格；**内置价格 ¥50/¥100 完全锁定，任何人（含超管）不可改**。
- 新建规格按钮下方显示配额：「还可创建 N 个」（普通管理员 ≤ 10，不含内置），配额用尽禁用。

## 5. 落地映射（Bootstrap 5）

### 5.1 规格选择器（下单页 `order/new.html`）

```html
<div class="spec-list">
  <label class="spec-card">   <!-- 2 列网格，radio 隐藏，选中加 .selected -->
    <input type="radio" name="spec_id_0" value="{{ spec.id }}" hidden>
    <span class="spec-name">{{ spec.name }}</span>
    <span class="spec-price">¥{{ '%.2f' % spec.price_yuan }}</span>
  </label>
</div>
```

```css
.spec-list { display: grid; grid-template-columns: 1fr 1fr; gap: 10px; }
.spec-card { border: 1px solid #E5E7EB; border-radius: 10px; padding: 10px; position: relative; cursor: pointer; }
.spec-card.selected { border: 2px solid #3D8B5F; background: #F4F9F5; }
.spec-name { font-size: 13px; font-weight: 500; }
.spec-price { display: block; font-size: 15px; font-weight: 500; color: #2E6B47; margin-top: 2px; }
.spec-card.selected::after { content: "✓"; position: absolute; top: 6px; right: 8px; ... }
```

### 5.2 规格管理页（`admin/specs.html`）

- 复用现有「管理员管理」卡片/表格样式，新增「规格」导航入口（`base.html` 导航栏）。
- 勾选面板复用 Bootstrap Modal；创建者 checkbox 加 `disabled`；内置规格行渲染「价格锁定」小标、隐藏改价/删除按钮。
- 接口：`/admin/specs`、`/admin/specs/create`、`/admin/specs/<id>/price`、`/toggle`、`/delete`、`/admins`（详见 `docs/12` §9；内置规格的 `/price` 服务端一律拒绝）。
